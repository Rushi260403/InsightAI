# Phase 8 - Exploratory Data Analysis

## Goal

Automatically analyze cleaned datasets using statistical
and exploratory data analysis techniques.

## EDA Workflow

1. Dataset Summary
2. Numeric Analysis
3. Categorical Analysis
4. Correlation Analysis
5. Outlier Detection

## Dataset Summary

- Total rows
- Total columns
- Column names
- Data types
- Missing values
- Duplicate rows

## Numeric Analysis

For numeric columns:

- Count
- Mean
- Median
- Minimum
- Maximum
- Standard deviation

## Categorical Analysis

For categorical columns:

- Unique values
- Value frequency
- Most frequent value

## Correlation Analysis

Calculate correlation between numeric columns.

## Outlier Detection

Use the IQR method.

Q1 = 25th percentile
Q3 = 75th percentile
IQR = Q3 - Q1

Lower limit = Q1 - 1.5 × IQR
Upper limit = Q3 + 1.5 × IQR
